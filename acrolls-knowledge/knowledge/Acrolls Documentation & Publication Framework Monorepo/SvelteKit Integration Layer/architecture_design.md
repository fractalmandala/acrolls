Two entry points are published via `package.json` exports: the root `.` (index.ts) re-exports types and functions from `@acrolls/docs` and `@acrolls/mdsvex`, plus SvelteKit-specific helpers; `./content` is a leaner subset that only exposes the content loader API. Both files implement the same core adapters — `markdownGlob`, `markdownRaw`, `customSource`, and the deprecated `createAcrollsDocsSource` — which translate Vite's `import.meta.glob` results into an Acrolls `ContentLoader`. The adapter normalizes glob keys against a configured `contentRoot` via shared `normalizeGlobPath`/`removeGlobRoot` helpers to produce document keys used by navigation/routing. The index entry additionally provides `createAcrollsSvelteKitMdsvexOptions` and `createAcrollsSvelteKitMdsvexPreprocessor`, which wrap the shared mdsvex factory with a default layout resolved at runtime from `@acrolls/svelte/PublicationLayout.svelte` and default extensions `.svx`/`.md`. Dependency direction is one-way: this package depends on `@acrolls/docs` and `@acrolls/mdsvex` as workspace peers and declares `@acrolls/svelte` and `mdsvex` as peer dependencies, keeping it a thin integration shim with no runtime Svelte component logic of its own.
