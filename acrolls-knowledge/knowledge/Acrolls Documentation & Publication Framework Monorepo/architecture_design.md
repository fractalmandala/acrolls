The repo is a pnpm workspace (`pnpm-workspace.yaml`) declaring `packages/*` and `examples/*`, with a root `package.json` orchestrating build, test, dev, and release scripts via `pnpm -r --filter`. Each child lives in `packages/<pkg>` and contributes one layer of the pipeline: `mdsvex/` compiles Markdown to Svelte modules; `sveltekit_integration/` exposes preprocessor factories and Vite content loaders that consume the mdsvex output; `docs_package/` assembles those into a pluggable SvelteKit shell with navigation chrome and discoverability utilities; `svelte_components/` provides the publication primitives (banner, callout, figure, video, image, layout) consumed by both the docs shell and host sites; `styles/` supplies the shared CSS/Sass theme tokens used by all UI layers; `cli/` onboards hosts and wires the above into existing projects; `acrolls_entrypoints/` re-exports the stable public surface as the `acrolls` npm package. Cross-package contracts are enforced through TypeScript (shared `tsconfig.base.json` with ES2022 target, strict mode, declaration+sourceMap output) and resolved at runtime via workspace protocol (`workspace:*`) so examples and the docs site always consume the local builds. The `scripts/verify-packed-consumer.mjs` and `release:pack`/`release` commands validate that the published `acrolls` tarball can be installed by a consumer before publishing.
