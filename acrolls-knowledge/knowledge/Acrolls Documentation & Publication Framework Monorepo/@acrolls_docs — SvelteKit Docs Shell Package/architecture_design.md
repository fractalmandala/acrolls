The package is organized as three cooperating layers under src/lib/ that are re-exported through a flat index.ts barrel: (1) the content source & collection API (content.ts, fields.ts, merge.ts, collection.ts) defines the StandardSchema-backed pluggable loader contract that produces DocsNav trees; (2) the navigation chrome layer (nav.ts, storage.ts, toc.ts plus DocsSidebar/DocsNavTree/DocsBreadcrumbs/DocsPager/DocsToc/DocsShell .svelte components) consumes those nav structures and persists sidebar open-state via localStorage; (3) the discoverability layer (seo.ts, og.ts, ai.ts, DocsSearch.svelte) generates SEO metadata, Open Graph images, llms.txt surfaces, and client-side Pagefind search. The package.json exposes these as separate entrypoints (`@acrolls/docs`, `@acrolls/docs/content`, `@acrolls/docs/collection`, plus styles), so consumers can import only the layer they need while the shared types in types.ts keep the layers type-safe against each other.
