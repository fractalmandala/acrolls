`pnpm build` runs `scripts/build.mjs` to compile `src/{foundation,default,docs,colors,theme}.sass` into sibling `.css` files with expanded output and no source maps; `pnpm check` invokes `scripts/check.mjs`. When consuming the Sass `theme` entry directly, a Node package importer must be registered in the Svelte/Vite config (e.g. Vite `css.preprocessorOptions.sass.importers: [new NodePackageImporter()]`) because it forwards `pkg:fractalthemer/*` URLs.
