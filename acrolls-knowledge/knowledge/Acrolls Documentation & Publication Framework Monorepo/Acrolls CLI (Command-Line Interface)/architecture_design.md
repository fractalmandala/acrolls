Single-package CLI (`@acrolls/cli`, private workspace package) exposing one binary `acrolls` via `package.json#bin`. The entry point `src/index.ts` is a shebang script that parses argv with the local `parseArgs` helper from `src/util.ts`, dispatches to command handlers, and exits with a numeric code. Each command lives in its own module: `integrate.ts` (host detection via `detectHost` and non-interactive Vite/svelte config patching), `onboarding.ts` (read-only step-plan generator producing a versioned `OnboardingPlan` JSON), `docs-init.ts` (writes starter `index.md` from `starter.ts`), `validate.ts` (corpus scanner using `@acrolls/mdsvex`'s `compile`, `normalizeAcrollsMarkdown`, `renderAcrollsArticleHtml` to produce diagnostics and exit codes), and `studio.ts` (in-memory HTTP server rendering a single `.md/.svx` file with embedded CSS/JS). Shared utilities (`exists`, `escapeHtml`, `resolvePackageDir`, `parseArgs`) live in `util.ts`. Tests co-located as `*.test.ts` files driven by Vitest (`vitest.config.ts`). Build uses `tsup` to emit ESM and a post-build `scripts/binify.mjs` to make the dist executable; the package depends only on `@acrolls/mdsvex`, `mdsvex`, and `svelte` at runtime.
