Single Svelte package (`@acrolls/svelte`) built by `svelte-package` from `src/lib/`, re-exporting seven Svelte components and two enhancement helpers via `src/lib/index.ts`. Components are presentation-only: `Publication.svelte` is the root `<article>` that applies the `acrolls` class and theme attribute, then mounts `enhanceCodeFrames` and `enhanceMermaid` on mount to progressively enhance DOM nodes produced at compile time. `PublicationLayout.svelte` is separately exported as a named entry for mdsvex default layout use. Enhancement helpers are pure DOM utilities — `code-frame-enhance.ts` injects Copy/Wrap buttons into `.acrolls-code-frame` slots, and `enhance-mermaid.ts` lazily imports `mermaid` to render `[data-acrolls-mermaid]` blocks into SVG canvases; both return cleanup functions so `Publication` can tear them down on unmount. All styling is delegated to host CSS (class names follow `acrolls-*` BEM convention); this package has no styles of its own.
