The module is a documentation-only leaf organized as a reference manual rather than executable code. Top-level Markdown files form the user-facing handbook (getting-started, cli, content-authoring, docs-shell, styles, packages, release, troubleshooting). The `adr/` subdirectory holds Architecture Decision Records with a numbered index (`0001`–`0004`) and a shared template, tracking decisions such as CLI-first onboarding, CUBE styling, fractalthemer theming, and theme-builder add-on scope. `playset/` provides a runnable sample docs site structured by topic folders (`01-introduction`, `02-components`, `03-presets`) demonstrating nested navigation and presets. `snippets/` contains copy-paste Svelte/SvelteKit/Vite fragments (layouts, page-load, nav config) referenced from the handbook pages. `evolution/` and `research/` store historical session logs, proposals, and component-extension research used to trace product evolution. `ogygia/` holds external research artifacts. Dependency direction is one-way: handbook pages link to each other and to the `snippets/` directory; no code imports this module.
