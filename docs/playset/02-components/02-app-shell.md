AppShell is the canonical application shell component in Fractal Styler. It provides a consistent, responsive layout for applications with a sticky header, optional navigation sidebar (left rail), optional table of contents (right rail), and an optional footer. Its primary purpose is to emit the exact markup structure required by the design system so that responsive behavior—such as drawer toggling and TOC folding—is driven by structure and registry classes rather than custom wiring.
