This package is a thin facade over sibling workspace packages (`@acrolls/svelte`, `@acrolls/docs`, `@acrolls/mdsvex`, `@acrolls/sveltekit`, `@acrolls/styles`). Its `package.json` declares an `exports` map that maps import paths like `./svelte`, `./docs`, `./content`, `./sveltekit`, `./mdsvex`, plus style entry points under `./styles/*` and `./docs/styles.*`. Each file in `exports/` is a one-line barrel that re-exports from the corresponding `@acrolls/*` package (e.g. `exports/svelte.js` → `export * from '@acrolls/svelte'`; `exports/content.js` combines collection exports with content helpers from `@acrolls/sveltekit/content`). The `bin/acrolls.mjs` CLI shim resolves `@acrolls/cli/dist/index.js` at runtime, falling back to a local path when the workspace link is missing, and spawns it as a child process while forwarding `ACROLLS_VERSION` via environment. Styles live directly under `styles/` as paired `.css`/`.sass` files and are declared as `sideEffects` so bundlers can tree-shake them safely. Dependencies on sibling packages are listed both as regular dependencies and `bundledDependencies` so the published package ships everything needed without requiring consumers to install each sub-package separately.
