Three sibling example projects under `examples/`, each a self-contained SvelteKit app with its own `package.json`:
- `kit-consumer/` (`@acrolls/example-kit`) is the primary integration demo. It consumes the local `acrolls` workspace package plus `fractalthemer` and renders docs via `DocsShell`, `DocsSeo`, `DocsSearch`, and `docsOgImagePath` from `acrolls/docs`. The route tree in `src/routes/docs/` uses a `[...slug]` catch-all that delegates rendering to `lib/docs/DocumentPage.svelte`; server data loaders in `+page.ts` fetch content through a `docs` source defined in `src/lib/docs/source`. Additional endpoints under `routes/` expose `/llms.txt`, `/llms-full.txt`, `/og/[slug]`, `/robots.txt`, and `/sitemap.xml` as `+server.ts` handlers.
- `docs-template/` (`@acrolls/example-docs-template`) is a minimal SvelteKit skeleton (no acrolls dependency) showing a basic layout using `+layout.svelte` / `+page.svelte` and a `vite.config.ts` + `svelte.config.js` setup for quick cloning.
- `starter/article.md` is a sample Markdown document with frontmatter used by the `acrolls validate` CLI command referenced inside it.
Dependency direction is one-way: examples depend on the published/local `acrolls` package; nothing in `packages/` depends back on `examples/`.
