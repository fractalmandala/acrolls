Root scripts coordinate the whole workspace: `pnpm build` builds every package under `packages/*`; `pnpm dev:docs` runs the docs shell and example kit in parallel; `pnpm check` type-checks all packages; `pnpm test` runs tests where present; `pnpm release:pack` packs the `acrolls` package with hoisted linker and `pnpm verify:packed-consumer` validates it against a real consumer before `pnpm release` publishes it.
