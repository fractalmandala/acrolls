The package is a thin adapter around `mdsvex` (peer dependency) built on the unified/remark/rehype ecosystem. `src/index.ts` exposes two entry points: `createAcrollsMdsvexOptions()` returns an options object configuring remark plugins (`remark-gfm`, `remark-mermaid-guard`), rehype plugins (`rehype-slug`, heading collection, anchor injection, table wrapping), and a custom Shiki-based highlighter; `createAcrollsMdsvexPreprocessor()` wraps it as a Vite-style markup preprocessor that runs source-safety normalization before mdsvex parsing, then post-processes the generated Svelte module to inject `metadata` and `__acrollsDocument` exports via AST analysis with `acorn` + `@sveltejs/acorn-typescript`. Internal layers are organized by concern: `source-safety.ts` scans prose lines for accidental Svelte/component/generic/object-literal syntax and wraps them in inline code; `document-diagnostics.ts` centralizes diagnostic/error types and renders fallback error-page Svelte modules; `highlighter.ts` lazily creates a single Shiki instance and decorates line spans with focus/highlight/diff attributes parsed from fence meta; `rehype-headings.ts`, `rehype-heading-anchors.ts`, `rehype-table-wrap.ts`, `rehype-code.ts` are individual rehype transformers; `remark-code-meta.ts` and `remark-mermaid-guard.ts` are remark transformers; `frontmatter.ts`, `document-facts.ts`, `render-html.ts` provide frontmatter splitting, document fact extraction, and server-side HTML rendering. Dependency direction flows inward: index orchestrates all submodules, which never import each other except `highlighter` depending on `code-meta`.
