Pure documentation leaf with no executable code; organized as a reference manual consumed by host projects. Top-level Markdown files form the user-facing handbook (getting-started, cli, content-authoring, docs-shell, styles, packages, release, troubleshooting) with README.md as the entry point providing a table-of-contents mapping intents to pages and listing Node/SvelteKit/pnpm requirements. `adr/` holds numbered Architecture Decision Records (0001–0004) tracked via a central index table with title/status/date columns and a shared template for new decisions. `playset/` is a runnable sample docs site structured by numbered topic folders (`01-introduction`, `02-components`, `03-presets`) demonstrating nested navigation and presets. `snippets/` contains standalone Svelte/SvelteKit/Vite fragments (layouts, page-load, nav config, vite.config) referenced from handbook pages rather than embedded inline. `evolution/` and `research/` store historical session logs, proposals, and component-extension research used to trace product evolution; `ogygia/` holds external research artifacts. Dependency direction is one-way: handbook pages link to each other and to the `snippets/` directory; nothing in this module imports or is imported by application code.
